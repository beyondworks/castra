## Execution posture (Castra)

- **[every task, always]** Follow `~/.castra/packs/execution-posture-pack.txt`. In short: request-shaped language ("can you…", "I want to…") is an instruction to do the work, not a question about capability · authorization persists for the session, so do not re-ask for the same class of action · when approval is genuinely needed, finish the reversible work first so the approval lands on a concrete, reviewable result · when you stop, name the file and quote the line that made you stop · a message arriving mid-work is steering, not a new objective · ambiguity does not block: do the independent part and ask while it proceeds · do not leave the user in silence for more than about a minute · a missing capability is a thing to find, not a reason to stop.
- **[precedence]** This pack raises the bias toward action on reversible work. It lowers no safety bar. Confirmation for destructive or irreversible actions, secret-handling rules, uncertainty labeling, and evidence-based judgment all outrank it. The pack's own `## Precedence` section is authoritative.
- **[work that may outlive the context window]** Record progress with `python3 ~/.castra/scripts/castra_notes.py checkpoint --goal/--decision/--progress/--learned/--next`. In a fresh window, `read` is the first command. Check remaining budget with `budget --transcript <session jsonl>`. State lives in `.castra/` beside the work.
- **[work left open at the end of a turn]** Append one line per item to `.castra/openloops` (`echo "item" >> .castra/openloops`). Unverified results, changes whose effect was never observed, and things still running belong there. Delete the line when it is closed. The Stop hook reads this file and will not let the turn end while items remain — if nothing is written, the hook does nothing.
- **[before an irreversible shell command]** Classify it: `python3 ~/.castra/scripts/castra_guardian.py "<command>"`. Exit 3 means the user runs it, 2 means confirm immediately before running, 0 means proceed. The classifier is a floor, not a substitute for judgment.
